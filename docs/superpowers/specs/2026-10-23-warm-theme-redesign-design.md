# BalanceWise 前端温暖手账风主题重设计

- 日期：2026-10-23
- 状态：已获用户确认
- 目标用户：lids（个人记账，非企业后台场景）

## 背景与问题

当前前端是典型 Element Plus 后台模板：深色侧边栏（#1e2235）、靛紫渐变 logo、灰底 #f5f6fa、默认组件样式。气质是「企业管理系统」，缺乏让人想记账的生活温度。

用户目标：**打开应用就有想记账的冲动**，侧重个人理财手账感。

## 设计方向：温暖手账风（默认主题）

- 底色：奶油米白 `#FAF7F0`；白色圆角卡片（16px 圆角、柔和暖阴影）
- 主色：暖橙 `#F28C38`；收入绿 `#3FA37A`；支出珊瑚红 `#E8684A`
- 文字：暖深灰棕 `#4A4238`，次要色 `#9A9084`
- 分类使用 emoji 图标（🍜 餐饮、🚌 交通等），未命中回退 💸

## 布局改造

- 移除深色侧边栏 → 顶部浅色导航栏：logo「🌿 BalanceWise」+ 圆角胶囊菜单项 + 右侧主题切换器与用户菜单
- 右下角常驻悬浮「✏️ 记一笔」FAB 按钮，任何页面一键进入记账页
- 登录 / 注册页：奶油底 + 居中暖色卡片

## 门面组件重设计（混合式）

保留 Element Plus 复杂控件（cascader、date-picker、table 等）不动业务逻辑，重设计以下门面：

1. **首页 Dashboard**：
   - 顶部暖橙渐变「净资产」大卡：问候语（下午好，lids ☀️）+ 大数字 + 账户数
   - 本月收入 / 本月支出两张小卡
   - 「最近流水」从表格改为手账列表：emoji + 分类名 + 备注 + 收支色金额
   - 图表配色改暖色圆角风格
2. **记一笔 Record**：类型切换为大号胶囊分段按钮；保存为大橙钮；金额突出
3. 其余页面（流水 / 账单导入 / 账户 / 分类 / 统计 / 用户中心）：以全局换肤为主，必要处微调

## 主题系统

- 4 套预设：`journal`（温暖手账，默认）、`mint`（清新薄荷）、`morandi`（雾粉莫兰迪）、`night`（暗夜质感）
- 实现：CSS 自定义属性按 `[data-theme="..."]` 作用域定义；同时覆盖 Element Plus 变量（--el-color-primary 等）
- 切换入口：顶栏调色盘图标下拉；写入 localStorage(`bw-theme`)，应用挂载前读取，避免闪烁
- 后端无改动，偏好仅存本地

## 非目标（YAGNI）

- 不新增业务功能、不改任何 API 调用与后端
- 不引入 UI 组件库替换，不推翻 Element Plus
- 主题不做服务端同步（本地存储即可）

## 验收标准

- `npm run build` 通过；默认主题为温暖手账；切换主题即时生效且刷新后保持
- 全部 10 个页面无深色侧边栏残留、无默认靛蓝主色残留
- 业务功能（记账、流水、统计、导入等）与改造前行为一致
